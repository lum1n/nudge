Nudge app icon assets

PNG/ contains 1024x1024 source icons cropped from the latest concept image, with the full rounded-square tile and mascot kept inside the image bounds.

- Nudge-iOS-Light.png: use as the Expo iOS icon or App Store source.
- Nudge-macOS-Dark.png: use as the macOS app icon source.
- iOS/Nudge.appiconset: Xcode iOS asset catalog.
- macOS/AppIcon.appiconset: Xcode macOS asset catalog.

Expo: set expo.ios.icon to ./nudge_app_icons/PNG/Nudge-iOS-Light.png. For macOS, use Nudge-macOS-Dark.png in the macOS target asset catalog. Review the result in the actual dock/home screen before release.
